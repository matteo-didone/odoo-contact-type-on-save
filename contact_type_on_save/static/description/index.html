Contact Type on Save

In Odoo 18, a new contact set as Company can be checked as if it were an Individual. This module makes the checks see the type you chose.

The problem

The contact form sends the company type, and Odoo turns it into the company flag only after the contact has been created. Checks that run before that still see an individual, and may refuse a perfectly valid company.

An example is the OCA Italian localization: a company whose fiscal code equals its VAT number is refused because the fiscal code "must have 16 characters", which is the rule for individuals. It happens when the contact is created from places that do not already assume a company, such as a quotation.

What this module does

When a contact is created or changed with a company type, the company flag is set together with it, so every check sees the right type. Individuals are still checked as individuals. A company flag given explicitly, as imports do, is left as it is.

Good to know

  • No settings, no new fields, no new views: install it and it works.
  • Installing it does not change your existing contacts.
  • An individual created where Odoo assumes a company, such as in Invoicing, is now checked as an individual too. Checks may be stricter there.
  • The same correction has been proposed to Odoo. Once Odoo includes it, you can uninstall this module.
  • Free, with no data sent anywhere.
